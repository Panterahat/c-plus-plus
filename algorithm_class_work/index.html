Algorithm: greedy graph coloring

  1. Each exam = a node in a graph.
  2. Two exams share an edge if any student takes both — they conflict.
  3. Sort nodes by degree (most conflicts first) — DSATUR heuristic.
  4. Assign the lowest available color so no two neighbors share one.
  5. Colors used = chromatic number = minimum slots needed.

Complexity analysis

  • VNumber of exams (vertices)
  • ENumber of conflict pairs (edges)
  • TTime complexity: O(V² + E)
  • SSpace complexity: O(V + E)
  • !Optimal coloring is NP-hard; greedy gives a polynomial-time approximation.
